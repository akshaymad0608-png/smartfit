# SmartFit — Smarter Fitness. Better Health.

A premium, production-ready fitness platform built with React, TypeScript, Vite and Tailwind CSS v4. Guided workouts, science-backed nutrition, precise health calculators and an AI coach — in one clean, fast, accessible experience.

![Stack](https://img.shields.io/badge/React-18-61dafb) ![TS](https://img.shields.io/badge/TypeScript-5.7-3178c6) ![Vite](https://img.shields.io/badge/Vite-6-646cff) ![Tailwind](https://img.shields.io/badge/Tailwind-4-38bdf8) ![PWA](https://img.shields.io/badge/PWA-ready-5a0fc8)

## ✨ Highlights

- **Design system** — semantic light/dark tokens, Inter type scale, soft elevation, one-swap theming
- **Reusable UI kit** — Button, Card, Badge, Input, Modal, Tabs, Accordion, Skeleton, Avatar, Counter, and more
- **Premium motion** — Framer Motion page transitions, scroll reveals, count-ups, animated charts (reduced-motion aware)
- **Health calculators** — BMI, BMR, TDEE, body fat, ideal weight, LBM, macros, protein & water, with on-demand **PDF export**
- **AI Coach** — on-device plan generator (workouts, meals, weekly plans, goals) built behind an async, API-ready interface
- **Dashboard** — weight, calorie, streak, hydration and goal charts (dependency-free SVG)
- **SEO** — per-page meta, canonical, Open Graph, Twitter cards and JSON-LD (Organization, Website, Breadcrumb, FAQ)
- **PWA** — installable, offline-capable via `vite-plugin-pwa` + Workbox
- **Accessible** — semantic HTML, keyboard nav, visible focus, skip link, ARIA, WCAG-minded contrast
- **Fast** — route-level code splitting, on-demand jsPDF, manual vendor chunks

## 🚀 Getting started

```bash
npm install
npm run dev        # http://localhost:5173
```

## 📦 Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Type-check (`tsc -b`) then production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | ESLint (TypeScript + React Hooks rules) |
| `npm run format` | Format with Prettier |
